Catat Hari Kerja

Hari penuh = 1 × gaji harian; setengah hari = 0,5 × gaji harian; mode jam = jumlah jam × (gaji harian ÷ 8). Lembur dihitung terpisah.

Backup & Restore Data

Backup menyimpan data pekerja dan seluruh catatan hari kerja menjadi file JSON. Simpan file tersebut di folder Download, Google Drive, atau tempat aman lainnya.

Restore akan mengganti data pekerja dan catatan yang ada saat ini dengan data dari file backup. Buat backup terbaru terlebih dahulu agar data saat ini tidak hilang.

Data tersimpan di penyimpanan browser pada perangkat ini. Buat cadangan secara berkala; data tidak otomatis tersinkron ke perangkat lain.
